# MSR Help

MultiStringReplace (msr) コマンドのヘルプです。

使用法:
msr [オプション] [対象]

オプション:
- -a, --add before after: パターンを追加
- -d, --del before: パターンを削除
- -c, --clear: パターンをクリア
- -l, --list: パターンをリスト
- -e, --export [file]: パターンをエクスポート
- -i, --import file: パターンをインポート
- -v, --version: バージョンを表示
- -h, --help: ヘルプを表示

対象がファイルの場合、置換して出力。
対象が文字列の場合、置換して出力。
