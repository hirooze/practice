# convert_heic_to_jpg.py の使用方法

このプログラムは、指定したフォルダ配下の `.heic` ファイルを再帰的に検索し、`.jpg` 形式に変換して同じフォルダ内に出力します。

## 必要なアプリケーション

- **Python**: バージョン 3.6 以上を推奨。公式サイトからダウンロードしてください。
  - ダウンロード: https://www.python.org/downloads/
- **Pillow**: Python の画像処理ライブラリ。
- **pillow-heif**: HEIC 形式の画像を扱うための Pillow の拡張ライブラリ。

## インストール方法

1. Python がインストールされていることを確認してください。コマンドプロンプトまたは PowerShell で以下のコマンドを実行してバージョンを確認できます：
   ```
   python --version
   ```

2. Pillow と pillow-heif をインストールします。コマンドプロンプトまたは PowerShell で以下のコマンドを実行してください：
   ```
   pip install pillow pillow-heif
   ```

## 実行方法

1. コマンドプロンプトまたは PowerShell を開きます。

2. このプログラムがあるフォルダ（`python/` フォルダ）に移動します：
   ```
   cd <このプログラムのフォルダパス>
   ```
   例: `cd .\practice\python`

3. 以下のコマンドでプログラムを実行します：
   ```
   python convert_heic_to_jpg.py "<検索対象のフォルダパス>"
   ```
   - `<検索対象のフォルダパス>`: `.heic` ファイルを検索したいフォルダの絶対パスを指定してください。パスにスペースが含まれる場合はダブルクォートで囲んでください。
   - 例:
     ```
     python convert_heic_to_jpg.py "C:\Users\hiroo\OneDrive\画像\カメラ ロール\2025\11"
     ```

4. プログラムが実行され、変換の進捗がコンソールに表示されます。変換が完了すると、同じフォルダ内に `.jpg` ファイルが出力されます。

## 注意点

- 元の `.heic` ファイルは削除されません。必要に応じて手動で削除してください。
- 大量のファイルを変換する場合、時間がかかる可能性があります。
- 変換に失敗した場合、エラーメッセージが表示されます。必要なライブラリが正しくインストールされているか確認してください。

## トラブルシューティング

- `ModuleNotFoundError` が発生した場合: Pillow または pillow-heif がインストールされていない可能性があります。上記のインストール手順を再度実行してください。
- パス関連のエラー: フォルダパスが正しいか確認してください。相対パスではなく絶対パスを使用することを推奨します。
