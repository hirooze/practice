# Bash Shell コマンドリスト

## 性能を評価するコマンド
|説明|コマンド|
|:---|:---|
|現在のメモリ|`free -h`|
|スワップの合計|`swapon --show`|
|スワップの動的な入出力|`vmstat 1 5`|
|プロセス別上位CPU|`ps aux --sort=-%cpu \| head -n 15`|
|プロセス別上位メモリ|`ps aux --sort=-%mem \| head -n 15`|
|容量の確認|`df -h`|

## その他使うコマンド
|説明|コマンド|
|:---|:---|
|ファイル・ディレクトリの圧縮|`tar -czvf <フォルダ>.tar.gz <元フォルダ>`|
|ファイル・ディレクトリの解凍|`tar -xzvf <ファイル名>.tar.gz`|
|空白、コメント欄除外|`grep -v -e ^#s*$ -e ^\s*$ <ファイルパス>`|
|テキストエディタ―で行番号表示|`:set number`|
